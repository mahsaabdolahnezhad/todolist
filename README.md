# To-Do List

A simple command-line To-Do List application built with Python. This project was made to practice object-oriented programming and working with CSV files.

## Features

- Add tasks with a name, description, and priority
- Display all tasks
- Remove tasks by their number
- Save tasks to a CSV file
- Load saved tasks when the program starts

## How to Run

Make sure Python is installed, then run:

```bash
py todo.py
```

Follow the menu options in the terminal to manage your tasks.

## Technologies

- Python
- CSV

## What I Learned

Through this project, I practiced classes and objects, lists, exception handling, file handling, and building a simple interactive menu in Python.
